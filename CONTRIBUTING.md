# Contribuer

Merci ! Narthex est jeune : les issues, les idées et les corrections de droit sont aussi précieuses que le code.

1. Lis [docs/PROMPT.md](docs/PROMPT.md) (règles du projet) et [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
2. `npm install`, puis `npm test` et `npm run typecheck`.
3. Une PR = une chose. Elle passe la CI sur macOS, Windows et Linux, et respecte la définition de « fini » du prompt.

Les textes visibles sont en français, au tutoiement. Le code et les commentaires sont en anglais.

**Le droit change.** Une règle fausse ou périmée dans `obligations.ts` est un bug prioritaire : ouvre une issue avec la source officielle.

En contribuant, tu acceptes que ta contribution soit publiée sous licence MIT.
